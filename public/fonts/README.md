# arimo-list-glyphs.woff2

The list glyphs of Google's Arimo font (● ○ ■ ◄ ►), which are Arial's
metrics: Google Docs draws list bullets with the bullet's own font, and the
Arimo served by Google Fonts leaves these characters out of its subsets.
Without them a browser without Arial draws bullets in whatever symbol font
it has, at another size. docs.css adds this file to the Arimo family for
those characters only.

Subset from Google Fonts (`css2?family=Arimo&text=●○■◄►`). Arimo is
