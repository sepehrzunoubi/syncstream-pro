Web Structured Data / Web Connection

For each subsegment of the industry (each person should work on one subsegment of their choosing, but make sure to talk/share this information in order to understand the industry as a whole):

  • Industry subsegment value proposition

    • For agents and the devs building them

      • APIs provide the data in a format ready for LLMs, i.e. providing the results in a format that agents can work with right away instead of having to scrape web pages and parse HTML.

    • For individual consumers and businesses

      • Agents can complete research, price checks, content monitoring, shopping, etc. on behalf of individual consumers and businesses, on up-to-date data, rather than relying on outdated training data.

    • For publishers and content owners

      • The licensing rails and the pay-per-crawl model enable publishers and content owners to be paid for every single time an agent reads content on their site, as opposed to content being scraped for free.

  • Industry subsegment overview and insights

    • Market size

      • The web scraping market is estimated to be around $1B in 2025 and is expected to grow to $2.3B by 2030 with a CAGR of around 18%. The web scraping market can be defined in different ways by different companies.

      • For example, some companies only focus on the use of scraping tools, whereas others look at the entire web data pipeline.

    • Actual adoption today

      • Tavily is a new app that enables users to manage tasks in different agent frameworks. It has reached over 1M monthly downloads with zero marketing spend.

      • Exa and Parallel both hit $2B+ valuations in under a month. Exa’s CEO claims that this year agents will search the web more than humans. 

    • The access layer is getting more closed, which is important to mention.

      • In July 2025 Cloudflare enabled by default blocking of AI crawlers for newly registered domains.

      • Also now, sites can charge for crawling of their pages. In August 2025 Microsoft announced the retirement of the Bing Search APIs, likely leading developers to the newer agent-centric APIs. This growing area of funding for search and extraction companies provides an opportunity for VCs to invest in companies delivering data to agents in a form they can use. Value will increasingly be derived from making data accessible and readable by agents, rather than owning the data.

        • EVIDENCE TO SUPPORT LAST SENTENCE: PhoenixAI launching Contextbase in November 2026.

  • Industry subsegment solutions (how AI agents are helped to find, retrieve and organize web information into data that can be used).

    • Search the live web using agent search APIs and return a ranked list of LLM-ready results with citations.

    • Scraping and crawling APIs: fetch web pages at scale using proxies, JS rendering and anti-bot measures.

    • Structured extraction - taxing web pages that are pretty messy and simply organizing their info into a clean predictable first that software/AI can easily read. 

    • Other important details with the solutions:

      • Websites can choose whether to allow AI tools to read their pages and if they should be charged for the privilege. Really Simple Licensing (RSL) allows websites to state access rights in a format that software can read. Cloudflare’s pay-per-crawl enables websites to charge for the crawl.

      • There are also a number of products on the market to allow developers to enable AI agents to access web search and web page reading services. Examples include LangChain, a toolkit for developing AI applications, which can be easily connected to Tavily’s search service.

      • Model Context Protocol (MCP) is also a standard for connecting AI applications to external tools and data, in order to minimize the amount of custom code developers have to write.

  • Industry subsegment start-up competitors (delve into companies from market map)

    • Agents are becoming the new users of web search tools. As such, firms like Exa have created web searching tools specifically designed for use by agents. In May 2026, Exa completed a $250 million Series C round backed by Andreessen Horowitz and was valued at $2.2 billion. 

    • In April 2026, Parallel closed a $100 million series B funded by Sequoia. The firm provides web data and deep research APIs to assist other agents. Parallel was founded by Parag Agrawal, who formerly served as CEO of Twitter. 

    • Firecrawl is an open source web crawler tool that converts websites into clean markdown. Firecrawl recently closed a $75 million series B in September 2026 led by Smash Capital and will be offering payment options for data retrieved from agent searches and a database called Alexandria. 

    • Agent-based search platform Tavily reported over 1 million monthly downloads of its search API. Insight Partners and Alpha Wave invested $25 million in a Series A round for Tavily in August 2025. 

    • Linkup offers a web search API for use in AI applications based on licensed content. Linkup closed a $10 million seed round. 

    • Olostep, which is still in its early stages, received backing from Vento Ventures for an API related to web search and structured data for use in AI systems.

  • Industry subsegment mature competitors (delve into companies from market map)

    • Google sells access to live Google Search results through its Gemini API: a paid feature called Grounding with Google Search lets an AI application answer with current web information and cite its sources.

    • Microsoft retired its standalone Bing Search APIs on August 11, 2025, and recommends that developers switch to Grounding with Bing Search, a feature that lets AI agents in Azure use current web information. This could create an opportunity for independent search providers serving developers who want a separate search service.

    • Cloudflare proxies a significant portion of the web and now has the power to grant or deny which agents are allowed in. AI-bot blocking by default and pay-per-crawl plans position them less as a CDN and more as a gatekeeper.

    • Bright Data owns one of the largest dedicated web data platforms (over 400M proxy IPs) and is beginning to reshape its scraping stack to support AI agents.

    • Apify operates a large marketplace for pre-made scrapers (known as Actors) and is positioning their platform to support agents.

    • SerpApi, Zyte, and Diffbot are well-known SERP, scraping, and extraction providers that have now begun to onboard AI users.

    • Common Crawl offers the free crawl database that many major training sets are built from. Their allowed uses will define what data from the open web means.
