# Solvely dataset

The x → z pairs the Style engine is trained on. `samples.jsonl` holds one
sample per line:

```json
{"id": "s001", "input": "<what the user typed>", "output": "<what Solvely produced>", "note": "optional"}
```

- `input` is the user's original text (x). `output` is the result we want to
  mirror (z). Both verbatim, whitespace included.
- `id` is any stable string; the lab uses it to name results and to keep the
  train/held-out split steady between runs.
- `note` is free text (where the sample came from, anything odd about it).

Samples are added by the developer, never by users of the app.

`config.json` sets the dataset name, operator notes that go into every
prompt, the held-out share for evaluation, and the seed of the split.

`compiled.json` is generated by `npm run style:compile` from the samples,
the fingerprint and the winning prompt candidate; the app reads it at build
time. `results/` holds the lab's run reports.
